HOW TO USE

User command reference

User commands

/start

Start the bot and see the welcome message.

/help

Show user help.

/files

Browse approved files.

/file <file_name>

Request an approved file by name.

/view

Choose an HTML file to open in a browser preview.

/viewht <file_name>

Get an HTML file to open in a browser.

/upload

Submit a file for the owner to review.

/done

Finish submitting files.

/cancel

Cancel an upload.
